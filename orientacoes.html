Sobre esta folha

  • É orientação prática, não parecer jurídico. Os prazos indicados são os mais comuns; o caso concreto pode ter outro.
  • A impressão sai só com a folha: o menu, os botões e este aviso ficam de fora.
  • Para editar o conteúdo: tudo está em js/orientacoes/dados.js, com o formato explicado no cabeçalho do arquivo. Escreva no imperativo e endereçado a quem vai levar o papel.
  • "Outras orientações" é para o caso isolado, e some ao recarregar a página. Orientação que você escreveu duas vezes já é conteúdo: leve para o arquivo acima.
